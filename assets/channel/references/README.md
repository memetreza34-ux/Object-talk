# Object-Talk Reference Assets

Hier liegen **nur vom Nutzer akzeptierte saubere Bildreferenzen** fuer wiederkehrende visuelle Elemente.

Diese Referenzen ergaenzen, aber ersetzen nicht:

```text
assets/channel/STYLE_REFERENCE.png
```

und nicht die Episode-Referenz:

```text
Bild_01.png
```

## Pilot 001 – geplante Referenzen

Sobald ein Element in einem echten Flow-Bild sauber und verbindlich aussieht, kann eine saubere Referenz gespeichert werden, zum Beispiel:

```text
oxygen-o2.png
carbon-dioxide-co2.png
red-blood-cell.png
hemoglobin.png
lungs.png
heart.png
mitochondrion.png
```

## Regeln

- nur akzeptierte finale Referenzen speichern
- keine Browser-Screenshots
- keine Collagen mit UI
- keine zufaellige Zwischenvariante
- Referenz muss die kanonische Form des Elements sauber zeigen
- Referenz darf keine fachlich falsche Anatomie erzwingen
- O2, CO2, rote Blutkoerperchen, Haemoglobin und Biologie bleiben im Pilot gesichtslos

## Flow-Nutzung

Bei einer Szene mit wiederkehrendem Element:

1. `STYLE_REFERENCE.png` anhaengen, falls vorhanden
2. `Bild_01.png` anhaengen
3. relevante Referenz aus diesem Ordner anhaengen
4. konkreten Szenenprompt ausfuehren

Ein Dateiname oder ein Satz im Prompt zaehlt nicht als angehaengte visuelle Referenz.
