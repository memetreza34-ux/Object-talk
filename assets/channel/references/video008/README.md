# Original-Video-008-Referenzen

Lege die **acht echten JPG-Frames aus der Verdauungs-Longform (008)** in diesen Ordner. Dateinamen, Zeitpunkte und Verwendung siehe `bildwelt/008-ORIGINAL-VIDEO-STYLE-REFERENCE.md`.

Die JPGs werden aus einer lokalen Kopie des Originalvideos erzeugt:
```bash
python tools/build_008_style_refs.py "/PFAD/ZUM/final-video(10).mp4"
```
Voraussetzung: `ffmpeg` ist installiert. Alternativ die vom ChatGPT-Upload bereitgestellte ZIP **entpacken** und die acht Dateien `008_*.jpg` hierher kopieren.

**Wichtig:** Dass eine README hier existiert, bedeutet noch NICHT, dass die echten Stilbilder ins Repo hochgeladen wurden. Upload der Bilder in Google Flow ist ein gesonderter praktischer Schritt; ein Textprompt kann ein visuelles Beispiel nicht ersetzen.

Beim nächsten Video zuerst echte 008-Frames in Flow verwenden; gewähltes Cover anschließend als zusätzliche Referenz, sofern es stilistisch zur 008-Welt passt. Videomotiv und sichtbarer Cover-Titel dürfen nicht in Folgebilder kopiert werden.
