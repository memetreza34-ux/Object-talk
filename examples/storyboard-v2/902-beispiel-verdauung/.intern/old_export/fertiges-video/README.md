# Fertiges Video

```text

```

- vollständig sein

- mindestens 5 Minuten lang sein
- das finale Voiceover vollständig enthalten
- alle Bilder gemäß `03_pipeline/pipeline.md` verwenden
- mit `Bild_01` beginnen
- keine schwarzen Frames oder Platzhalter enthalten
