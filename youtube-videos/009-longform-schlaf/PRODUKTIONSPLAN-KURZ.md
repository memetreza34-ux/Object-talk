# Produktionsplan – 009 Schlaf

**Thema:** Was passiert während des Schlafs in deinem Körper?

**Status:** Phase 1 erstellt; Bilder, Audio und MP4 stehen noch aus.

**Laufzeit-Ziel:** 6:00–7:00 (erst nach Voice zu bestätigen).

**Skript:** 1.058 Wörter, **85 Bilder**. 1.10x Voice. Kurze erste Cover-Sprachzeile für ~3–4 Sekunden.

**Aufbau:** Hook → Schlafdruck/Adenosin und innere Uhr → Einschlafen/Schlafstufen → Tiefschlaf/Herz/Hormone → Lernen/Gedächtnis → Immunsystem → REM/Träume → Schlafzyklen → Schluss.

**Art Direction:** Clean Animated Biology Illustration, wenige Labels (0–2), Cover exakt `Was macht dein Körper nachts?`, starke Schrift-Hintergrund-Kontraste, helles Abendlicht → dunkle Nacht → morgendliches Licht, wissenschaftlich plausible Anatomie. Nicht auf jeder Szene derselbe Pastellhintergrund. Keine Schulbuch-Mehrfachtafeln; stattdessen ein visueller Lehrpunkt je Bild.

**Remotion:** nur Ton, Vollbildbilder, Bewegung, Schnitt und Render; KEIN sichtbarer Text. Keine Dateinamen oder Produktions-IDs im Video. Jedes Bild einmal, maximal 7 Sekunden.

**Medienablauf:** Recherche/Claim-Matrix → Script → Flow-Bilder im Fünferbatch → Bild-QA → finales Voiceover → Whisper-Timing → Render → vollständige Video-QA → Export mit Caption + vollständigem getimtem Script + SRT + MP4.

**Freigabe:** Ohne echtes finales Audio/Bilder und bestandene Validatoren kein YouTube-ready-Status.
