ANTIGRAVITY – PILOT 007 „WARUM BEKOMMST DU GÄNSEHAUT?“

Arbeite ausschließlich nach dem Repository.

Projekt:
`youtube-videos/007-pilot-gaensehaut/`

ZIEL
Erzeuge aus Voice + 20 finalen Google-Flow-Bildern einen klaren animierten Biologie-Erklärfilm mit maximal 2:00 Minuten Laufzeit.

AUDIO
- Roh-TTS niemals direkt rendern.
- `tools/prepare_audio.py` mit `--speed 1.10` verwenden.
- lange TTS-Pausen vor Whisper/Timeline komprimieren.
- `final-voiceover.wav` ist die einzige Timing-Quelle.
- finale Laufzeit über 120 Sekunden = HARD FAIL.

BILDER
- exakt 20 eindeutige finale Bilder.
- Dateinamen intern `Bild_01.png` bis `Bild_20.png`.
- diese Dateinamen/Bildnummern dürfen NIEMALS sichtbar im Video erscheinen.
- keine Bildduplikate.
- kein Bild länger als 7 Sekunden.
- bei längerem Sprachbeat echten zusätzlichen visuellen Beat planen; niemals einfach duplizieren.

BILDWELT
- `Clean Animated Biology Illustration`
- Bilder bleiben 100 % Vollbild.
- keine dauerhaften Rahmen, Seitenleisten oder Kartenlayouts.
- biologische Labels sind bereits Bestandteil der akzeptierten Flow-Bilder.

REMOTION – HARTE REGEL
Remotion erzeugt KEINEN sichtbaren Text.
`03_pipeline/overlay-plan.json` muss leer/deaktiviert bleiben.

Remotion darf nur:
- finales Audio
- exaktes Timing
- sanfte Push-/Pull-Bewegungen
- leichte Pans
- saubere Schnitte
- dezente nicht-textliche Übergänge
- Render

Remotion darf NICHT:
- Zwischenüberschriften
- Key-Facts
- Summary-Text
- Untertitel
- Labels
- Bildnummern
- Szenennummern
- Dateinamen
- sonstige sichtbare Schrift erzeugen

SCHNITT
- harte saubere Schnitte als Standard.
- Push/Pull ca. 2–4 %.
- Pan ca. 20–30 px.
- keine hektischen Zooms, kein Shake, Bounce oder Meme-Transition.

VORBEREITUNG
```bash
python -m pip install -r tools/requirements.txt
python tools/validate_planning_v2.py youtube-videos/007-pilot-gaensehaut
python tools/prepare_phase3.py youtube-videos/007-pilot-gaensehaut
```

RENDER
```bash
cd renderer
npm install
npm run render -- ../youtube-videos/007-pilot-gaensehaut/04_export/fertiges-video/final-video.mp4
```

FINAL-QA
- Laufzeit <= 120 Sekunden
- 1920×1080 / 30 fps
- Audio vollständig
- 20 Bilder vollständig
- keine Szene >7s
- keine Bildduplikate
- keine sichtbare Bild-/Szenennummer oder Dateiname
- keine Remotion-Schrift
- Flow-Labels korrekt
- Gänsehaut nicht wie Ausschlag/Krankheit darstellen
- Haaraufrichtemuskel korrekt am Haarfollikel
- Kälte und Emotion als mögliche Auslöser, ohne zu behaupten, jede Emotion löse Gänsehaut aus
- Tierfell-Nutzen nicht auf Menschen übertragen

Bei Konflikt oder fehlenden Assets: FAIL statt raten.
