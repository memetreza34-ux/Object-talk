# Timing-Dateien

Dieser Ordner wird in Phase 3 automatisch gefüllt.

Erwartete Dateien:

```text
whisper-words.json
subtitles.srt
timeline.json
```

## Bedeutung

- `whisper-words.json` enthält die Wort-Zeitstempel des finalen Voiceovers.
- `subtitles.srt` kann als YouTube-Untertitel verwendet werden.
- `timeline.json` enthält die endgültigen Start-/Endzeiten aller Bilder.

Diese Dateien werden **nicht von Hand geschätzt**. Sie entstehen aus dem finalen Audio mit den Tools im Ordner `/tools`.
