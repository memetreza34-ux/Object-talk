# GOOGLE FLOW – MASTERPROMPT TEMPLATE

## ROLE

You produce the final 16:9 still images for the German Object-Talk biology/health explainer channel.

Use the approved **Clean Animated Biology Illustration** world from:
- `bildwelt/BIOLOGY-ILLUSTRATION-WORLD.md`
- `bildwelt/FLOW-STYLE-BLOCK.txt`
- `engine/VISIBLE-TEXT-STANDARD.md`

Create a clean 16:9 animated biology illustration with simplified but recognizable anatomy, smooth organic shapes, clean outlines, soft gradients, subtle depth, bright calm background and clear biological colors. Keep exactly one main teaching idea, preferably 2–4 important visible elements, and make the frame immediately understandable.

## TEXT / INFORMATION RULES

Normal frames:
- 0–2 German labels maximum
- prefer no label when the image is self-explanatory
- each label 1–2 words preferred, maximum 3 words
- no full sentences
- no quotation marks around labels in the final artwork
- omit nonessential structures and text
- if a frame needs several teaching ideas, split it into more images

Cover / first hook frame:
- exactly ONE visible text block
- exact title only
- no anatomy labels
- no subtitle
- no extra explanation
- no pointer text

Text contrast:
- light/pale background → dark charcoal/navy text
- dark background → light text
- never light text on light background
- never dark text on dark background
- put text in calm negative space when possible

Weak contrast, extra cover text or information overload = REJECT AND REGENERATE.

## CRITICAL: PRODUCTION IDS ARE METADATA ONLY

Never render any production identifier inside an image.

Forbidden visible text includes:
- Bild_01 / Bild_02 / Bild 01 / BILD 01
- IMAGE 01
- Szene 01 / Scene 01
- filenames
- asset IDs
- prompt headings
- internal production notes

The identifiers are used only to save and organize files. The ONLY visible text allowed is the exact German title/labels explicitly requested in the scene prompt.

## IMAGE DESIGN

Prefer varied compositions such as:
- cutaway
- cross-section
- macro view
- cell interior
- transport route
- cause/effect
- before/after
- comparison
- scale transition

Do not make every frame a centered object with labels.

## HARD FAILS

Regenerate if:
- biology is wrong
- main process is unclear
- more than one major teaching idea competes in the frame
- image is too complex
- nonessential information is added
- a normal frame has more than 2 labels
- a label has more than 3 words
- cover has any text besides its title
- text contrast is weak
- labels are wrong/unreadable/unnecessary
- any asset/image/scene number is visible
- any filename/prompt heading is visible
- the image drifts into photoreal medicine, medical CGI, glossy 3D, feature-animation, toy/kids-book style, corporate infographic style, random icons or severe AI artifacts
