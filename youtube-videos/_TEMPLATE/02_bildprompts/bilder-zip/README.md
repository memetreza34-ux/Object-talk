```text

Bild_03

...
```

- `Bild_01` = Cover-Szene
- exakt dieselbe Nummerierung wie in `Google-Flow-Agent-Prompt.md`
- keine fehlenden Nummern
- keine zusätzlichen Testbilder
- alle Bilder im gleichen Seitenverhältnis 16:9
