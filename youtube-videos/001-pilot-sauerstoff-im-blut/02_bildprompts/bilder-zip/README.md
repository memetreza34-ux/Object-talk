# Flow-Bilder-ZIP – Pilot

Lege hier nach Abschluss von Google Flow **eine ZIP** mit den final akzeptierten Bildern ab.

Erwartet:

```text
Bild_01.png
Bild_02.png
...
Bild_26.png
```

Regeln:
- genau 26 Bildnummern
- keine Lücke
- keine doppelte Nummer
- keine verworfenen Varianten
- keine temporären Flow-Dateinamen
- `Bild_01` ist der akzeptierte Master Style Frame
- Fehlerbilder erst nach Recovery-PASS in die ZIP aufnehmen

Die technische Pipeline ordnet ausschließlich nach `Bild_XX`, niemals nach ZIP-Reihenfolge.
