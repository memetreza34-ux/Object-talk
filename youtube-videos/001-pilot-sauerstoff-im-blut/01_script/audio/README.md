# Audio – Pilot 001

Lege hier genau eine rohe Voice-Datei ab (`.wav`, `.mp3`, `.m4a` oder `.aac`).

Der Sprechertext muss 1:1 `../script.txt` entsprechen.

Dieser interne Pilot ist bewusst ungefähr 2–2,5 Minuten lang. Er testet die verbesserte Bildwelt, feste visuelle Symbolik, selektive Remotion-Overlays, Synchronisierung und Render-Pipeline. Normale Kanalvideos bleiben mindestens 5 Minuten lang.
