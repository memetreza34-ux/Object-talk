# Audio – 2-Minuten-Pilot

Lege hier genau eine rohe Voice-Datei ab (`.wav`, `.mp3`, `.m4a` oder `.aac`).

Der Sprechertext muss 1:1 `../script.txt` entsprechen.

Dieser interne Pilot ist bewusst nur ungefähr 2 Minuten lang. Er testet Bildwelt, V2-Planung, Flow, Synchronisierung und Remotion. Er ersetzt nicht die normale Longform-Regel für veröffentlichte Kanalvideos.
