# ANTIGRAVITY – PILOT 001 „SAUERSTOFF VON DER LUNGE BIS ZUR ZELLE“

Arbeite ausschließlich technisch nach dem Repository.

Projekt:

```text
youtube-videos/001-pilot-sauerstoff-im-blut/
```

## Ziel

Erzeuge aus Voice + 28 finalen Flow-Bildern einen hochwertigen ca. 2–2,5-minütigen Object-Talk-Erklärfilm.

Der Film soll **wie ein zusammenhängender kurzer 3D-Animationsfilm** wirken und nicht wie eine Diashow.

## Verbindliche Kanal-DNA

Autoritativ:

```text
bildwelt/OBJECT-TALK-CHANNEL-DNA.md
bildwelt/OBJECT-TALK-STYLE-EXAMPLE.md
youtube-videos/001-pilot-sauerstoff-im-blut/02_bildprompts/STYLE-LOCK-BEISPIEL.md
```

Die ursprüngliche Kanalidee ist verbindlich:

- virale Object-Talk-Character-Szenen nur bei natürlich passenden Lebensmitteln/Gegenständen
- Inside-the-Body-Szenen normalerweise gesichtslos
- beide Ebenen sehen wie dieselbe hochwertige 3D-Animationsserie aus
- **kein erfundenes O₂-Maskottchen**

## Video-Look

- hochwertige stilisierte 3D-Feature-Animation
- klar animiert, nicht fotorealistisch
- weiche gerundete Formen
- matte/satinierte Premium-Materialien
- warme filmische Beleuchtung
- starke Tiefe
- keine Medical-CGI-Anmutung
- keine Anatomiesoftware
- keine Stock-3D-/Toy-Optik
- keine Anime-/Comic-/Meme-Effekte
- Vollbild-Erklärbilder bleiben dominant
- sichtbarer Text ausschließlich Deutsch

## Schnittprinzip – Reise statt Diashow

Die 28 Bilder bilden eine durchgehende Reise:

```text
Einatmen
→ Atemwege
→ Lunge
→ Alveole
→ Blut
→ rotes Blutkörperchen / Hämoglobin
→ Herz
→ Arterien
→ Kapillare
→ Muskelzelle
→ Mitochondrium
→ CO₂ zurück zur Lunge
```

Kontinuität entsteht über:

- gleiche O₂-Farbe/Form
- gleiche Blutkörperchen
- gleiche Anatomie-Stilisierung
- gleiche Licht-/Materialwelt
- sinnvolle Bewegungsrichtung
- klare Makro→Mikro-Übergänge

Nicht über einen Character-Guide.

Wichtig:

- Bewegungsrichtung zwischen Szenen möglichst erhalten
- bei O₂-Transport die visuelle Flussrichtung logisch fortsetzen
- keine zufälligen Richtungswechsel
- harte saubere Schnitte sind Standard
- kurze weiche Überblendung nur bei echtem Maßstabs-/Ortswechsel
- keine dekorativen Übergangseffekte

## Kamerabewegung

- Push/Pull nur ca. 3–4 %
- Pan ca. 20–30 px bei 1080p
- weiche Ease-in/Ease-out-Bewegung
- Bewegung bevorzugt entlang des erklärten Prozesses
- Mechanismusbilder: leichter Pan entlang des Weges
- Label-/Vergleichsszenen: bei Bedarf statisch
- keine aggressiven Ken-Burns-Zooms
- kein Shake, Bounce oder Meme-Motion

## Bild_01 / Cover

`Bild_01` ist Cover, erster Shot und Master Style Frame.

- keinen zweiten Titel darüberlegen
- Hook vollständig sichtbar lassen
- Covermotiv nicht anschneiden
- ruhiger hochwertiger Start
- nur sehr dezenter Push-in, wenn die Komposition nicht beschädigt wird
- keine zusätzlichen Anatomie-Labels auf dem Cover

## Vorbereitung

Vom Repo-Root:

```bash
python -m pip install -r tools/requirements.txt
python tools/validate_planning_v2.py youtube-videos/001-pilot-sauerstoff-im-blut
python tools/prepare_phase3.py youtube-videos/001-pilot-sauerstoff-im-blut
```

`prepare_phase3.py` muss:

1. `scene-map.json` deterministisch aus `phase1-scenes.json` erzeugen
2. Script/Scene-Map validieren
3. Voice kanonisieren
4. ZIP `Bild_01.png` bis `Bild_28.png` importieren
5. Bilder technisch validieren
6. Whisper-Worttimings erzeugen
7. Script strikt gegen Audio ausrichten
8. exakte Timeline bauen
9. Renderer-Runtime inklusive `overlay-plan.json` vorbereiten

## Rhythmus

- echte Voice-Timeline ist autoritativ
- Hook sofort verständlich
- normale Erklärung überwiegend 3–6 Sekunden pro Bild
- keine unnötig langen Standbilder
- Bildwechsel nur bei echtem visuellen Sinnwechsel
- letzte Szene endet exakt mit dem Voice-over

## Text-/Overlay-Regel

- vorhandene korrekte deutsche Flow-Labels nicht unnötig wiederholen
- falsches/unlesbares Flow-Label nach `label-plan.json` sauber in Remotion ersetzen
- `03_pipeline/overlay-plan.json` ist für zusätzliche Overlays autoritativ
- keine Captions oder kompletten Voice-over-Sätze
- keine Marketingtexte
- keine UI-/Dashboard-Karten
- keine großen Glasboxen oder schwarzen Textflächen
- helle schwebende Typografie mit dezentem Schatten / kleiner Unterstreichung
- Anatomie und Hauptprozess niemals verdecken

## Story-Beats

Zusätzliche Overlays nur an großen Übergängen:

- Lunge → Blut
- Weiter zum Herzen
- Blut → Muskelzelle
- In die Zelle
- CO₂ entsteht
- Zurück zur Lunge

- O₂/CO₂/RBC/Hämoglobin bleiben konsistent
- keine erzwungenen Character-/Mascot-Elemente
- kein Medical-/Realismus-Drift

- Kamerabewegung wirkt ruhig und absichtlich
- letzte Szene endet exakt mit dem Voice-over
