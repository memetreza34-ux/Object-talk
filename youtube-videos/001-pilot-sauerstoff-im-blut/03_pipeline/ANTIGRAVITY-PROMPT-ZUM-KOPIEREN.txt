# ANTIGRAVITY – PILOT 001 „SAUERSTOFF VON DER LUNGE BIS ZUR ZELLE“

Arbeite ausschließlich technisch nach dem Repository.

Projekt:

```text
youtube-videos/001-pilot-sauerstoff-im-blut/
```

## Ziel

Erzeuge aus Voice + 28 finalen Flow-Bildern einen hochwertigen ca. 2–2,5-minütigen Object-Talk-Erklärfilm.

Der Film soll **wie ein zusammenhängender kurzer 3D-Animationsfilm** wirken und ausdrücklich **nicht wie eine Bildershow**.

## Verbindliche Kanal-DNA

Autoritativ:

```text
bildwelt/OBJECT-TALK-CHANNEL-DNA.md
bildwelt/OBJECT-TALK-STYLE-EXAMPLE.md
youtube-videos/001-pilot-sauerstoff-im-blut/02_bildprompts/STYLE-LOCK-BEISPIEL.md
```

Die neue Object-Talk-Welt hat Vorrang vor älteren allgemeineren Stilbeschreibungen.

Der wiederkehrende **O₂-Guide** ist der visuelle rote Faden des Films. Wenn er in aufeinanderfolgenden Bildern sichtbar ist, muss der Schnitt seine Reise klar fortsetzen.

## Video-Look

- Premium-3D-Feature-Animation, klar stilisiert und nicht fotorealistisch
- Object-Talk-Charaktersprache sichtbar beibehalten
- O₂-Guide, Augenstil, Blutkörperchen, Materialien und Farbwelt niemals neu interpretieren
- keine zusätzlichen Realismusfilter
- keine Medical-CGI-Anmutung
- keine anatomische Dokumentations-/Softwareoptik
- keine Stock-3D-/Toy-Optik
- keine Anime-/Comic-/Meme-Effekte
- Vollbild-Erklärbilder bleiben dominant
- sichtbarer Text ausschließlich Deutsch

## Schnittprinzip – Reise statt Diashow

Die Reihenfolge der Bilder folgt der echten Sauerstoffreise.

Behandle die 28 Bilder als **eine durchgehende Bewegung durch dieselbe Welt**:

```text
Einatmen
→ Atemwege
→ Lunge
→ Alveole
→ Blut
→ rotes Blutkörperchen / Hämoglobin
→ Herz
→ Arterien
→ Kapillare
→ Muskelzelle
→ Mitochondrium
→ CO₂ zurück zur Lunge
```

Wichtig:

- Bewegungsrichtung zwischen aufeinanderfolgenden Szenen möglichst erhalten
- wenn der O₂-Guide rechts aus einer Szene reist, soll die nächste Szene seine Reise logisch fortsetzen
- Makro→Mikro-Wechsel klar und filmisch wirken lassen
- keine zufälligen Richtungswechsel
- keine unnötigen Übergangseffekte
- harte saubere Schnitte sind Standard
- sehr kurze weiche Überblendung nur dann, wenn sie einen echten Maßstabs-/Ortswechsel verständlicher macht
- niemals Übergänge nur als Dekoration einsetzen

## Kamerabewegung

Kamerabewegung soll die Object-Talk-Welt lebendig machen, ohne die Standbilder künstlich wirken zu lassen.

- Push/Pull nur ca. 3–4 %
- Pan ca. 20–30 px bei 1080p
- weiche Ease-in/Ease-out-Bewegung
- bei sichtbarem O₂-Guide Bewegung bevorzugt in seine Reiserichtung
- Character-Hero-Shots: sehr dezenter Push-in
- große Mechanismusbilder: leichter Pan entlang des Prozesses
- Label-/Vergleichsszenen: bei Bedarf statisch
- wenn ein Bild schon sehr dynamisch komponiert ist: keine zusätzliche starke Bewegung
- keine aggressiven Ken-Burns-Zooms
- kein Shake, Bounce oder Meme-Motion

## Bild_01 / Cover

`Bild_01` ist Cover, erster Shot und Master Style Frame.

- keinen zweiten Titel darüberlegen
- Hook vollständig sichtbar lassen
- O₂-Guide und Covermotiv nicht anschneiden
- ruhiger, hochwertiger Start
- nur sehr dezenter Push-in, wenn die Komposition dadurch nicht beschädigt wird
- keine zusätzlichen Anatomie-Labels auf dem Cover

## Vorbereitung

Vom Repo-Root:

```bash
python -m pip install -r tools/requirements.txt
python tools/validate_planning_v2.py youtube-videos/001-pilot-sauerstoff-im-blut
python tools/prepare_phase3.py youtube-videos/001-pilot-sauerstoff-im-blut
```

`prepare_phase3.py` muss:

1. `scene-map.json` deterministisch aus `phase1-scenes.json` erzeugen
2. Script/Scene-Map validieren
3. Voice kanonisieren
4. ZIP `Bild_01.png` bis `Bild_28.png` importieren
5. Bilder technisch validieren
6. Whisper-Worttimings erzeugen
7. Script strikt gegen Audio ausrichten
8. exakte Timeline bauen
9. Renderer-Runtime inklusive `overlay-plan.json` vorbereiten

## Rhythmus

Die echte Voice-Timeline ist autoritativ.

- Hook sofort verständlich
- normale Erklärung überwiegend ca. 3–6 Sekunden pro Bild
- keine unnötig langen Standbilder
- Bildwechsel nur bei echtem visuellen Sinnwechsel
- keine Szene künstlich verlängern, nur damit ein Zoom fertig wird
- wichtige Übergänge der Reise dürfen etwas mehr Ruhe bekommen
- letzte Szene endet exakt mit dem Voice-over

## O₂-Guide-Kontinuität

Wenn der O₂-Guide sichtbar ist:

- gleiche Form und Größe relativ zur Szene
- gleiche Cyan-Farbe
- gleiche Augenform / Catchlights / Mimik-Sprache
- keine zufälligen Arme/Beine ergänzen
- keine neue Charakterversion erzeugen
- nicht spiegeln, wenn dadurch die Bewegungsrichtung unlogisch wird

Der Guide ist **visueller Begleiter**, nicht Sprecher vor einer Tafel.

## Text-/Overlay-Regel

- vorhandene korrekte deutsche Flow-Labels nicht unnötig wiederholen
- falsches/unlesbares Flow-Label nach `label-plan.json` sauber in Remotion ersetzen
- `03_pipeline/overlay-plan.json` ist für zusätzliche Overlays autoritativ
- keine Captions oder kompletten Voice-over-Sätze einblenden
- keine Marketingtexte erfinden
- keine UI-/Dashboard-Karten
- keine großen Glasboxen oder schwarzen Textflächen
- helle schwebende Typografie mit dezentem Schatten / kleiner Unterstreichung
- Anatomie, Character-Gesichter und O₂-Guide niemals mit Overlay verdecken

## Story-Beats

Zusätzliche Overlays nur an großen Übergängen:

- Lunge → Blut
- Weiter zum Herzen
- Blut → Muskelzelle
- In die Zelle
- CO₂ entsteht
- Zurück zur Lunge

Nicht mehr Kapitel erfinden.

## Finale QA

Vom Repo-Root:

```bash
python tools/qa_final.py \
  youtube-videos/001-pilot-sauerstoff-im-blut/04_export/fertiges-video/final-video.mp4 \
  youtube-videos/001-pilot-sauerstoff-im-blut/01_script/audio/final-voiceover.wav \
  --min-seconds 115
```

Danach visuellen QA nach `engine/VISUAL-QUALITY-GATE.md` durchführen.

PASS nur wenn:

- Film wirkt wie **eine durchgehende Object-Talk-3D-Reise**
- Bild_01 setzt sichtbar die Welt für alle Folgeframes
- O₂-Guide bleibt konsistent
- keine Szene driftet in Medical-CGI, Realismus, Stock-3D oder Toy-Look
- O₂, CO₂, rote Blutkörperchen und Hämoglobin bleiben konsistent
- deutsche Labels korrekt und lesbar
- Overlays verdecken keine wichtigen Motive
- Bewegungen sind ruhig, absichtlich und folgen der Reise
- keine Szene wirkt wie ein zufälliges Einzelbild aus einer anderen Serie
- letzte Szene endet exakt mit der Voice

Bei Konflikt: FAIL statt raten.
