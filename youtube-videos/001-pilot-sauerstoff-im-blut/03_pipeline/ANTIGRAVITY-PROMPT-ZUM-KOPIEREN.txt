# ANTIGRAVITY – PILOT 001 „SAUERSTOFF VON DER LUNGE BIS ZUR ZELLE“

Arbeite ausschließlich technisch nach dem Repository.

Projekt:

```text
youtube-videos/001-pilot-sauerstoff-im-blut/
```

## Ziel

- erster echter kleiner Pilot mit ca. 2–2,5 Minuten
- 28 Bilder
- hohe visuelle Dichte
- stark stilisierte hochwertige 3D-Animationsfilm-Welt
- Vollbild-Erklärbilder bleiben dominant
- sichtbarer Text ausschließlich Deutsch
- wichtige Flow-Labels erhalten; nicht unnötig doppeln
- selektive zusätzliche Remotion-Overlays aus `03_pipeline/overlay-plan.json`
- keine Anime-/Comic-/Meme-Effekte
- keine dauerhaften Untertitelblöcke
- keine kreative Neuzuordnung von Szenen
- das Ergebnis soll wie ein bewusst geschnittener Erklärfilm wirken, nicht wie eine Diashow

## Video-Look

Die freigegebene Bildwelt ist verbindlich:

```text
bildwelt/APPROVED-VISUAL-WORLD.md
```

Die Bilder müssen im finalen Video ihre hochwertige 3D-Wirkung behalten. Keine zusätzlichen Filter, die Farben oder Materialien verfälschen.

Kamerabewegung:

- ruhig und hochwertig
- Push/Pull nur etwa 3–4 %
- Pan nur etwa 20–30 px bei 1080p
- weiche Ease-in/Ease-out-Bewegung
- Bewegungsrichtung folgt dem erklärten Prozess, wenn sinnvoll
- nicht jede Szene automatisch bewegen
- wichtige Label-/Vergleichsszenen dürfen bewusst statisch bleiben
- keine aggressiven Ken-Burns-Zooms
- keine Wackler, Shake- oder Meme-Bewegungen

## Cover / Bild_01

Bild_01 ist bereits Cover, erster Shot und Master Style Frame.

- keinen zweiten Titel oder Hook darüberlegen
- Cover  sauber und ruhig starten lassen
- nur sehr dezenter Push-in, falls die Bildkomposition dadurch nicht beschädigt wird
- Titelbereich und Hauptmotiv vollständig sichtbar lassen
- kein zusätzlicher Text auf Gesicht, Anatomie oder Titelzone

## Vorbereitung

Vom Repo-Root:

```bash
python -m pip install -r tools/requirements.txt
python tools/validate_planning_v2.py youtube-videos/001-pilot-sauerstoff-im-blut
python tools/prepare_phase3.py youtube-videos/001-pilot-sauerstoff-im-blut
```

`prepare_phase3.py` muss:

1. `scene-map.json` deterministisch aus `phase1-scenes.json` erzeugen
2. Script/Scene-Map validieren
3. Voice kanonisieren
4. ZIP `Bild_01.png` bis `Bild_28.png` importieren
5. Bilder technisch validieren
6. Whisper-Worttimings erzeugen
7. Script strikt gegen Audio ausrichten
8. exakte Timeline bauen
9. Renderer-Runtime inklusive `overlay-plan.json` vorbereiten

## Schnitt und Rhythmus

Die echte Voice-Timeline ist autoritativ.

- Hook schnell und klar
- normale Erklärung überwiegend 3–6 Sekunden pro Bild
- keine unnötig langen Standbilder
- Bildwechsel nur bei echtem visuellen Sinnwechsel
- harte saubere Schnitte sind Standard
- keine auffälligen Übergänge ohne inhaltlichen Grund
- wenn ein Bild schon viel interne Bewegung zeigt, Remotion-Bewegung reduzieren
- wenn ein Label am Rand liegt, keine Bewegung verwenden, die es anschneidet

## Text-/Overlay-Regel

- Bild_01 enthält bereits den deutschen Cover-Hook; keinen zweiten Cover-Hook darüberlegen
- vorhandene korrekte deutsche Flow-Labels nicht unnötig wiederholen
- wenn ein Flow-Label sichtbar falsch/unlesbar ist, denselben im Label-Plan festgelegten Begriff sauber in Remotion ersetzen
- `03_pipeline/overlay-plan.json` ist für zusätzliche Overlays autoritativ
- Overlay-Text exakt übernehmen
- keine zusätzlichen Captions oder Marketingtexte erfinden
- Vollbild bleibt Hauptdarsteller
- Overlays als klare schwebende Typografie, nicht als UI-/Dashboard-Karten
- keine großen Glasboxen oder schwarzen Textflächen
- helle Typografie mit dezentem Schatten und kleiner Unterstreichung bevorzugen
- Anatomie und Prozess dürfen niemals von Overlays verdeckt werden

## Story-Beats

Die wenigen zusätzlichen Overlays markieren nur große Übergänge:

- Lunge → Blut
- weiter zum Herzen
- Blut → Muskelzelle
- in die Zelle
- CO₂ entsteht
- zurück zur Lunge

Keine zusätzlichen Kapitel erfinden.

## QA

Vom Repo-Root:

```bash
python tools/qa_final.py \
  youtube-videos/001-pilot-sauerstoff-im-blut/04_export/fertiges-video/final-video.mp4 \
  youtube-videos/001-pilot-sauerstoff-im-blut/01_script/audio/final-voiceover.wav \
  --min-seconds 115
```

Danach visuellen QA nach `engine/VISUAL-QUALITY-GATE.md` durchführen.

Besonders prüfen:

- Bild_01 funktioniert als Cover, Hook und Style-Anker
- Bildwelt bleibt stark stilisiert und driftet nicht in Fotorealismus
- O₂, CO₂, rote Blutkörperchen und Hämoglobin bleiben konsistent
- wichtigste sichtbare Strukturen sind sinnvoll auf Deutsch beschriftet
- keine englischen oder zufälligen Texte
- keine falschen/doppelten Labels
- Remotion-Overlays liegen nicht über zentraler Anatomie
- Overlays wirken nicht wie UI-Karten
- Kamerabewegung wirkt ruhig und absichtlich
- kein Bild steht unnötig lange nur mit Zoom
- letzte Szene endet exakt mit dem Voice-over

Bei Konflikt: FAIL statt raten.
