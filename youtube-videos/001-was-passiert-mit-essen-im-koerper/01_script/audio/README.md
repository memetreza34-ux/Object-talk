# Audio – Phase 2

1. `../script.txt` exakt 1:1 in die vom Nutzer gewählte Voice-KI kopieren.
2. Keine Wörter hinzufügen, entfernen oder umformulieren.
3. Fertige Audiodatei hier ablegen, bevorzugt als:
   - `voiceover.wav` oder
   - `voiceover.mp3`
4. Die Stimme wird vom Nutzer selbst erzeugt.
5. Nach der Ablage übernimmt Phase 3 die kanonische Audioaufbereitung, Whisper-Wortzeiten und Synchronisierung.

Wichtig: Nach der finalen Voice-Erzeugung `script.txt` nicht mehr verändern, ohne das Audio neu zu erzeugen.
