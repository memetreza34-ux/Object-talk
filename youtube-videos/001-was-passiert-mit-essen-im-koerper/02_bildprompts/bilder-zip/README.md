# Google-Flow-ZIP hier ablegen

Nach Abschluss aller 36 Bilder in Google Flow:

1. Prüfen, dass final `Bild_01.png` bis `Bild_36.png` vorhanden sind.
2. Alle 36 Bilder gemeinsam als eine ZIP-Datei herunterladen/packen.
3. ZIP unverändert in diesen Ordner legen.

Phase 3 importiert die Bilder ausschließlich anhand der Bildnummern. Die Reihenfolge innerhalb der ZIP wird nicht verwendet.

Nicht manuell umsortieren, wenn die Dateien bereits korrekt `Bild_01` bis `Bild_36` heißen.
