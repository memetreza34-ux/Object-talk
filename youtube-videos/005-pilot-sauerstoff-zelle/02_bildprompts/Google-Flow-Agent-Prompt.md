# GOOGLE FLOW – PILOT 005

## Ziel
Erzeuge 22 einzelne 16:9-Bilder für das Video **„Wie kommt Sauerstoff in deine Zelle?“**.

## Verbindliche Bildwelt
Autoritativ: `bildwelt/BIOLOGY-ILLUSTRATION-WORLD.md`

Use this visual language for every image:

Create a clean 16:9 animated biology illustration with simplified but recognizable anatomy, smooth organic shapes, clean outlines, soft gradients, subtle depth, bright calm background and clear biological colors. Keep the composition simple, visually attractive and immediately understandable. Use only 1–3 short German labels with clean pointer lines when labels are needed. No realistic tissue, no medical CGI, no glossy 3D, no clutter, no unnecessary text.

## Produktionsregeln
- generate every image individually
- one dominant teaching idea per image
- keep each scene simple; normally 2–5 important visual elements
- use only the exact German text listed for the scene
- no asset IDs or scene numbers inside the artwork
- do not make all images use the same centered composition
- vary between overview, cutaway, close-up, cross-section, transport route and cell interior
- anatomy must remain simplified but scientifically recognizable
- if a label is misspelled, regenerate the image
- keep the same illustration language across all 22 images
