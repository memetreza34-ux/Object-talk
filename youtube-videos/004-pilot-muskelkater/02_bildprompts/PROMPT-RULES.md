# Pilot 004 – Prompt Rules

Dieser Pilot nutzt ausschliesslich die freigegebene Kanalbildwelt:
**Clean Animated Biology Illustration**.

Autoritativ:
- `../../../bildwelt/BIOLOGY-ILLUSTRATION-WORLD.md`
- `../../../bildwelt/FLOW-STYLE-BLOCK.txt`

## Prompt-Form

Jeder Flow-Prompt bleibt kurz:

```text
[kanonischer Styleblock]
[einfach beschriebene Szene]
[sichtbarer Prozess]
Add only these German labels: "...", "...", "...".
No clutter, no realistic tissue, no unnecessary details or extra text.
```

## Pilot-Regeln

- 2–5 zentrale Elemente pro Bild
- ein Hauptprozess
- normalerweise 1–3 kurze deutsche Labels
- Muskel-/Gewebe-, Nerven-/Signal-, Vergleichs-, Querschnitts- und Makroansichten abwechseln
- keine alten 2.5D-/Soft-3D-/Premium-3D-Prompts verwenden
- nicht jedes Bild gleich komponieren
- keine sichtbaren Assetnummern
- falsche Labels regenerieren

Der vorhandene `label-plan.json` ist die inhaltliche Quelle fuer geplante Beschriftungen. Bei zu vielen Labels wird auf die 1–3 wichtigsten gekuerzt, ohne den Lehrinhalt zu verfälschen.
