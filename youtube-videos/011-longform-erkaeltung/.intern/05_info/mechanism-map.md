# Mechanism Map – Video 011 Erkältung

## Frage
Warum läuft die Nase bei einer Erkältung – und wer verursacht die Beschwerden eigentlich?

## Kausale Kette
Tröpfchen/Hände → Nasenschleimhaut (Schleim, Flimmerhärchen) → Andocken am Rezeptor → Virusvermehrung in der Zelle → Alarm-Botenstoffe → Abwehrzellen + Gefäßerweiterung → Schwellung, Schnupfen, Niesen, Halsweh, ggf. Fieber → Antikörper → Abklingen → neuer Virustyp, neue Erkältung.
