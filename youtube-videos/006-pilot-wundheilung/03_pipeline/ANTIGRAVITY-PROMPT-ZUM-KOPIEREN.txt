ANTIGRAVITY – PILOT 006 „WAS PASSIERT BEI EINEM SCHNITT?“

Arbeite ausschließlich nach dem Repository.

Projekt:
`youtube-videos/006-pilot-wundheilung/`

ZIEL
Erzeuge aus Voice + 22 finalen Google-Flow-Bildern einen klaren animierten Biologie-Erklärfilm mit maximal 2:00 Minuten Laufzeit.

AUDIO ZUERST
- Roh-TTS niemals direkt rendern.
- `tools/prepare_audio.py` mit `--speed 1.10` verwenden.
- lange TTS-Pausen vor Whisper/Timeline komprimieren.
- `final-voiceover.wav` ist die einzige Timing-Quelle.
- finale Laufzeit über 120 Sekunden = HARD FAIL.

BILDER
- exakt 22 eindeutige Dateien: `Bild_01.png` bis `Bild_22.png`.
- diese Dateinamen sind reine Produktionsmetadaten und dürfen niemals im finalen Video sichtbar werden.
- keine Bildduplikate.
- kein Bild länger als 7 Sekunden.
- falls ein Sprachbeat länger als 7 Sekunden ist: nicht einfach Bild duplizieren; Pipeline stoppen und echten zusätzlichen visuellen Beat planen.

BILDWELT
- `Clean Animated Biology Illustration`
- Bilder bleiben 100 % Vollbild.
- keine dauerhaften Rahmen, Seitenleisten oder Kartenlayouts.
- sichtbare biologische Labels sind bereits Bestandteil der akzeptierten Flow-Bilder.

REMOTION – HARTE TEXTSPERRE
Remotion erzeugt KEINEN sichtbaren Text.

Verboten:
- Zwischenüberschriften
- Key-Facts
- Summary-Zeilen
- Kapiteltexte
- Callouts
- Untertitel / Captions als Standard
- anatomische Labels
- Textkarten
- sichtbare Bildnummern oder Szenennummern
- Dateinamen / Asset-IDs
- Korrektur von Flow-Schrift

`03_pipeline/overlay-plan.json` muss `status: DISABLED` und `scenes: []` enthalten.
Ein nicht-leerer Overlay-Plan = HARD FAIL.

REMOTION DARF NUR
- Timing
- Audio
- dezente Push/Pull/Pan-Bewegung
- statische Bilder
- saubere Schnitte / dezente nicht-textliche Überblendungen
- Rendering

SCHNITT
- harte saubere Schnitte als Standard.
- Push/Pull ca. 2–4 %.
- Pan ca. 20–30 px.
- keine hektischen Zooms, kein Shake, Bounce oder Meme-Transition.

VORBEREITUNG
```bash
python -m pip install -r tools/requirements.txt
python tools/validate_planning_v2.py youtube-videos/006-pilot-wundheilung
python tools/prepare_phase3.py youtube-videos/006-pilot-wundheilung
```

RENDER
```bash
cd renderer
npm install
npm run render -- ../youtube-videos/006-pilot-wundheilung/04_export/fertiges-video/final-video.mp4
```

FINAL-QA
- Laufzeit <= 120 Sekunden
- 1920×1080 / 30 fps
- Audio vollständig
- keine Szene >7s
- keine Bildduplikate
- 22 Bilder vollständig
- Flow-Labels korrekt
- **0 von Remotion erzeugte sichtbare Textelemente**
- keine sichtbaren Bild-/Szenennummern
- keine sichtbaren Dateinamen oder Asset-IDs
- Blutstillung, Entzündungs-/Aufräumphase, Aufbau und Remodeling fachlich plausibel
- nicht suggerieren, dass die Phasen strikt getrennt sind
- keine schwere Infektion darstellen, wenn der Text nur normale frühe Wundheilung erklärt

Bei Konflikt oder fehlenden Assets: FAIL statt raten.
