# Object-Talk

Zentrale Produktionsbasis für die visuelle Welt des Kanals **Object-Talk / FoodSpricht**.

Ziel: lange YouTube-Videos über Ernährung, Gesundheit und Biologie mit einer **einheitlichen, wiedererkennbaren 3D-Bildwelt** produzieren.

## Kernprinzip

Die Bildwelt verbindet zwei Ebenen:

1. **Viral Object-Talk** – sprechende Lebensmittel und Objekte mit großen Augen, klarer Mimik und starker Persönlichkeit.
2. **Inside-the-Body** – verständliche, kindgerechte 3D-Darstellungen von Organen, Zellen, Blut, Nervensystem und biologischen Prozessen.

Beide Ebenen müssen wie **dieselbe Animationsserie** wirken: semi-realistisch, klar animiert, warm, hochwertig, nicht fotorealistisch.
