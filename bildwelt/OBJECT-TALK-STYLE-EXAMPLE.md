# Object-Talk Style Example – echte Kanalreferenz

Status: **VERBINDLICHES TEXTBEISPIEL**

Diese Datei konkretisiert die ursprüngliche Kanalidee: **virale Object-Talk-Figuren + Inside-the-Body in derselben hochwertigen 3D-Animationsserie**.

## Beispiel A – echter Object-Talk-Character

Ein Gegenstand oder Lebensmittel bleibt klar als echtes Objekt erkennbar und wird nur dort personifiziert, wo es natürlich passt.

Beispiel:

```text
Create a premium 16:9 viral Object-Talk scene with one anthropomorphic apple as the clear main character. Keep the apple shape unmistakable. Give it large dark oval eyes with small white catchlights, expressive eyebrows, a simple readable mouth and small stylized arms and legs. Use soft rounded 3D forms, clean matte materials, warm cinematic lighting, gentle rim light, rich controlled colors and strong depth. The result should feel like a frame from a high-end animated feature film, modern and expressive but not babyish. No photorealism, no stock 3D, no toy render, no anime, no comic.
```

## Beispiel B – Inside-the-Body aus derselben Welt

Die Biologie übernimmt **Licht, Material, Rundungen, Farbqualität und Rendergrad**, aber normalerweise **keine Gesichter**.

```text
Using the same Object-Talk channel world, create a premium 16:9 inside-the-body scene of stylized lungs and branching bronchi. Keep all biology faceless. Use the same soft rounded sculpted forms, clean matte premium materials, warm cinematic lighting, soft rim light, rich controlled colors and strong depth as the Object-Talk character scenes. The lungs must look like part of the same animated film, not medical CGI or anatomy software. Add only the German label “Bronchien”.
```

## Beispiel C – Makro-/Mikro-Szene

```text
Using the same channel world, create a cinematic macro view of soft rounded alveoli beside a smooth capillary. Keep the anatomy simplified, clean and faceless. Show pale-cyan oxygen particles crossing from the alveolus into the blood. Use the same premium animated-film materials, lighting and depth as the Object-Talk scenes. Add only the German labels “Lungenbläschen”, “Kapillare” and “Sauerstoff”. No wet tissue, no realistic medical rendering.
```

## Harte Regel

Ein Molekül, Organ oder eine Zelle bekommt **nicht automatisch Augen oder Mund**.

Nur wenn die Szenenidee ausdrücklich einen echten Character braucht, wird personifiziert. Ansonsten bleibt die Biologie gesichtslos und trägt nur dieselbe hochwertige 3D-Animationsfilm-DNA.

## PASS

Ein Bild ist PASS, wenn:

1. es sichtbar aus derselben hochwertigen 3D-Animationsserie stammt
2. Object-Talk-Charaktere stark und klar wirken, wenn sie wirklich gebraucht werden
3. Inside-the-Body-Szenen nicht in medizinischen Realismus driften
4. Materialien, Licht, Formen und Farbqualität konsistent bleiben
5. kein erfundenes Mascot die eigentliche Erklärung verdrängt
6. sichtbarer Text nur Deutsch ist

## FAIL

- zufälliges niedliches Maskottchen
- Molekül mit Augen nur weil das Thema Biologie ist
- medizinisches CGI
- realistischer Mensch als Stilbruch
- Corporate-3D
- billiger Toy-Look
- andere Animationswelt pro Szene
