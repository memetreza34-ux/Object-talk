# Beispielprompts – Clean Animated Biology Illustration

Diese Beispiele zeigen die gewuenschte Prompt-Laenge, Informationsdichte und Textnutzung. Sie sind keine festen Szenen fuer jedes Video.

Verbindlich dazu:
- `BIOLOGY-ILLUSTRATION-WORLD.md`
- `FLOW-STYLE-BLOCK.txt`
- `../engine/VISIBLE-TEXT-STANDARD.md`

Grundregel:
- ein Bild = eine Hauptidee
- bevorzugt 2–4 wichtige sichtbare Elemente
- normale Bilder 0–2 Labels, nur wenn wirklich noetig
- Label bevorzugt 1–2 Woerter, maximal 3 Woerter
- sichtbare Labels ohne Anfuehrungszeichen rendern
- heller Hintergrund → dunkle Schrift
- dunkler Hintergrund → helle Schrift
- wenn das Bild ohne Label klar ist: kein Label

## Cover – nur Titel

```text
Create a clean 16:9 animated biology illustration showing a strong macro view of human skin changing from smooth skin to goosebumps. Keep the visual simple and immediately understandable.
Exactly one visible text block: Warum Gänsehaut? Title only. No anatomy labels, no subtitle, no extra text. Use dark navy text on the bright background with strong contrast.
```

## Blut – Sauerstofftransport

```text
Create a clean 16:9 animated biology illustration with simplified but recognizable anatomy, smooth organic shapes, clean outlines, soft gradients, subtle depth and a bright calm background.
Show a simple blood vessel with several red blood cells. Small cyan oxygen particles move toward and attach to the red blood cells.
Render only these German labels without quotation marks: Sauerstoff and rotes Blutkörperchen. Use dark text on the pale background.
No clutter, no realistic tissue, no unnecessary details or extra text.
```

## Zelle – Mitochondrium

```text
Create a clean 16:9 animated biology illustration with smooth organic shapes, clean outlines, soft gradients and subtle depth.
Show one simplified human cell with a clear nucleus and several mitochondria. Highlight one mitochondrion as the main focus.
Render only the German label Mitochondrium without quotation marks. Use dark high-contrast text in calm negative space.
Keep the scene simple and easy to understand.
```

## Nervenzelle – Signal

```text
Create a clean 16:9 animated biology illustration with smooth organic forms, soft shading and a bright calm background.
Show one simplified nerve cell with branching dendrites and a long axon. A bright signal travels clearly along the axon from left to right.
Render only these German labels without quotation marks: Axon and Signal. Use dark text on the light background.
No unnecessary structures or extra text.
```

## Muskel – belastete Muskelfaser

```text
Create a clean 16:9 animated biology illustration with simplified muscle anatomy, smooth organic shapes, clean outlines and soft depth.
Show several red muscle fibers. One central fiber has a small visibly stressed area and a nearby nerve ending reacts to small signaling particles.
Render only these German labels without quotation marks: belasteter Bereich and Nervenende. Use strong contrast and keep labels away from busy anatomy.
Keep the image simple, clear and not crowded.
```

## Lunge – Sauerstoff ins Blut

```text
Create a clean 16:9 animated biology illustration with simplified anatomy, clean outlines, soft gradients and subtle depth.
Show one lung alveolus next to a small blood vessel. Oxygen particles move clearly from the alveolus into the blood.
Render only these German labels without quotation marks: Lungenbläschen and Sauerstoff. Use dark high-contrast text on the bright background.
No unnecessary anatomy or clutter.
```

## Darm – Nährstoffaufnahme

```text
Create a clean 16:9 animated biology illustration with smooth organic shapes, clear colors and soft depth.
Show a simplified section of the small intestine with a few intestinal villi. Nutrient particles move through the intestinal wall into a nearby blood vessel.
Render only the German label Nährstoffe without quotation marks. Use dark high-contrast text in calm negative space.
Keep everything simple and immediately understandable.
```

## Prozess ohne Text

```text
Create a clean 16:9 animated biology illustration showing a tiny hair muscle contracting and pulling a hair more upright while the surrounding skin forms a small goosebump. Make the before-and-after change visually obvious.
No visible text. The biological change must explain itself through the illustration alone.
```

## Was diese Beispiele bewusst NICHT tun

- keine 3-Label-Standardbilder
- keine ganzen Saetze im Bild
- keine hellen Labels auf hellem Hintergrund
- keine Beschriftung jeder sichtbaren Struktur
- keine Zusatzlabels auf dem Cover
- keine Informationssammlung in einem einzigen Frame

Wenn fuer das Verstaendnis mehr Information gebraucht wird, wird ein weiteres Bild geplant.
