# Explainer Style Lock – Object-Talk

Status: **KANONISCH / VERBINDLICH**

Diese Datei definiert die Bildwelt fuer normale Erklaerszenen des Kanals.

## Zielbild

Die Erklaerszenen verwenden eine **moderne stilisierte 2.5D / Soft-3D Educational Illustration**.

Leitidee:

**80 % animierte Illustration + 20 % Soft-3D-Tiefe + 0 % Medical-CGI.**

Die Bilder sollen klar animiert und gestaltet wirken, nicht realistisch. Sie duerfen leichte 3D-Tiefe, Volumen und weiche Schatten besitzen, bleiben aber bewusst vereinfacht und anschaulich.

## Verbindliche Merkmale

- stark stilisierte, gerundete, einfache Formen
- klare Silhouetten und ein dominantes Hauptmotiv
- matte bis leicht satinierte Oberflaechen
- weiche Farbverlaeufe und subtile Schatten
- leichte Vordergrund-/Mittelgrund-/Hintergrundstaffelung
- ruhige, helle Hintergruende
- keine dramatische Kinoinszenierung
- keine realistischen Gewebetexturen
- pro Bild genau eine Hauptaussage
- maximal wenige, gezielte Zusatzobjekte
- visuelle Klarheit wichtiger als Detailgrad

## Semantisches Farbsystem

Diese Farben bleiben kanalweit moeglichst stabil:

- Sauerstoff / O2: Cyan / Tuerkis
- rote Blutkoerperchen: tiefes warmes Rot
- Blutgefaesse: Coral / Rot
- Organe: Peach / Coral
- Muskelzellen: warmes Orange / Apricot
- CO2: weiches Violett
- ATP / Energie: warmes Gelb / Gold
- Hintergruende: Creme / sehr helles Blau / weiches Beige

## Biologie-Regel

Anatomie wird **vereinfacht, aber fachlich erkennbar** dargestellt.

Nicht zeigen:

- fotorealistische Organe
- nasses Fleisch / Gewebe
- Poren / realistische Haut
- medizinische CGI-Optik
- Mikroskop-Fotorealismus
- ueberkomplexe Kapillar-/Gewebedetails
- Horror-/Ekeloptik

Die Illustration darf wissenschaftlich vereinfachen, solange die erklaerte Richtung, Beziehung und Funktion korrekt bleibt.

## Kompositionsregel

Jede Szene erklaert **eine** Sache.

Beispiel:

`Lungenblaeschen -> Sauerstoff -> Blut`

Nicht gleichzeitig Herz, Muskel, Mitochondrium und weitere Nebenthemen in dasselbe Bild packen.

## Textregel

- Cover: nur die festgelegte Hook / der Titel
- normale Szenen: 0–2 kurze deutsche Labels bevorzugt
- maximal 3 Labels nur wenn fachlich wirklich noetig
- keine Textwaende
- kein englischer sichtbarer Text

## Object-Talk-Verhaeltnis

Diese Explainer-Bildwelt ersetzt **nicht** den Character-Look der eigentlichen Object-Talk-Reels.

- Lebensmittel / Alltagsobjekte als Character: hochwertiger stilisierter 3D-Object-Talk-Look mit Augen, Mimik und Character-Performance
- Biologie / Prozesse / Erklaerframes: diese 2.5D / Soft-3D Illustration, normalerweise gesichtslos

Beide Modi teilen helle Farben, weiche Rundungen, saubere Materialien und eine freundliche moderne Gestaltung.

## Flow-Stilblock

```text
Use a modern stylized 2.5D / soft-3D educational illustration style. Keep the image clearly animated and illustrated, not realistic. Use rounded simplified shapes, matte surfaces, soft gradients, subtle shadows, gentle depth and a clean readable composition. One clear visual idea per frame. Biology should be simplified but recognizable. Use consistent semantic colors: oxygen cyan/turquoise, blood cells deep warm red, vessels coral-red, organs peach/coral, muscle cells apricot-orange, CO2 soft violet, ATP warm yellow-gold, background light cream or soft blue. Prioritize visual clarity over detail. No photorealism, no medical CGI, no wet tissue, no realistic microscopic texture, no dark sci-fi world, no cosmic background, no human presenter, no anatomy mannequin, no cluttered infographic.
```

## Hard FAIL

- wirkt realistisch oder medizinisch
- wirkt wie Anatomiesoftware
- wirkt wie Mikroskopfotos
- zu viele Objekte / mehrere Erklaerziele gleichzeitig
- dunkler kosmischer oder Sci-Fi-Look
- unklare Bewegungsrichtung
- Hauptmotiv nicht sofort erkennbar
- notwendige semantische Farben inkonsistent
- unnoetig viele Labels
